Sticky Notes Application

A Django web application that allows users to create, view,
edit and delete sticky notes.

	Features:

- View all notes
- Create a new note
- View note details
- Edit existing notes
- Delete notes
- Form validation
- Unit tests
- Basic CSS styling

	Technologies:

- Python
- Django
- HTML
- CSS
- SQLite

	Installation:

Clone or download the project.

Create a virtual environment:

1.
bash
python3 -m venv venv


Activate it on macOS:

2.
bash
source venv/bin/activate


Install Django:

3.
bash
python3 -m pip install django


Apply migrations:

4.
bash
python3 manage.py migrate


Run the application:

5.
bash
python3 manage.py runserver


Open the application at:

6.
text
http://127.0.0.1:8001/
```

	Running Tests:

bash
python3 manage.py test notes
